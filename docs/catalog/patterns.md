# 패턴 카탈로그

7단계(유지보수)에서 새로 배운 패턴이 쌓이는 곳. 3단계(패턴 분석)에서 검색/참조합니다.
항목은 Volere 카드 형식으로 통일합니다.

## 항목 형식

```
## <패턴 이름>

- 트랙: 알고리즘 / 프로젝트
- 계층: 설계 패러다임 / 구현 기법 패턴 (알고리즘) — 또는 아키텍처 스타일 (프로젝트)
  ([03-pattern-analysis](../03-pattern-analysis/01-algorithm-paradigms.md) 분류 참고)
- 태그:
- 언제 쓰는가:
- 트레이드오프:
- 예시 문제/사례:
- 처음 배운 날짜/출처:
```

> `트랙`/`계층` 필드는 항목이 쌓이면 알고리즘 기법과 아키텍처 패턴이 검색에서
> 뒤섞이는 걸 막기 위해 있습니다.

이 브랜치엔 아직 등록된 패턴이 없습니다 — 위 형식으로 7단계 회고에서 하나씩
쌓입니다. (`main` 브랜치에는 실제로 쌓인 예시가 있습니다: 해시맵 원패스
탐색, 스택 기반 매칭, 환경변수 기반 Config 오버라이드, 한 번 순회 최솟값
추적 — 형식을 참고하고 싶으면 거기를 보세요.)
