# 프로젝트 트랙 — 문제 저장 템플릿

출처: GitHub Issue Template 표준 필드 (버그 리포트 / 기능 요청 공통 골격)

## 템플릿

```
요약(Description):
재현 절차 또는 배경(Steps to reproduce / Motivation):
기대 동작 또는 제안 해결책(Expected behavior / Proposed solution):
환경 정보(있다면 - OS/버전 등):
대안 검토(기능 요청일 경우 - Alternatives considered):
```

## 핵심 규칙

버그 리포트에서는 **재현 절차가 가장 가치 있는 정보**입니다 — 다른 사람(미래의 나 포함)이
그대로 따라 할 수 있는 수준으로 남기세요.

## 작성 예시

```
요약: 로그인 후 세션이 5분 만에 만료됨
재현 절차: 1) 로그인 2) 5분 대기 3) 아무 API 호출 → 401 에러
기대 동작: 세션은 최소 30분 유지되어야 함
환경 정보: 로컬 개발 서버, JWT 만료시간 설정값 확인 필요
대안 검토: (해당 없음, 버그이므로)
```
